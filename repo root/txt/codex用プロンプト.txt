あなたはフロントエンドエンジニアとして、このリポジトリ内に 静的Webサイトのフロントエンド一式 を実装します。

このサイトは GitHub Pagesで公開する静的サイトです。
バックエンド・API・ビルドツールは使用しません。

使用技術

HTML

SCSS

CSS

Vanilla JavaScript

1 作業範囲

このリポジトリには既存ドキュメントがあります。
既存ファイルへの影響を防ぐため、実装は site/ フォルダ配下のみで行ってください。

以下のフォルダは 絶対に編集しないでください

css/
js/
images/
design/
prompts/

3 CSS衝突防止ルール

既存ドキュメントとCSS衝突を防ぐため

全ページの body を

<body class="perfume-site">

にしてください。

CSSは必ず

.perfume-site

配下で定義してください。

例

.perfume-site .l-header {}
.perfume-site .c-button {}
.perfume-site .p-home-hero {}
4 CSSファイル

CSSファイルは

site/assets/css/perfume.css

を使用してください。

HTMLからの読み込み

<link rel="stylesheet" href="assets/css/perfume.css">
5 SCSS設計

SCSSは

FLOCSS + BEM

構成にしてください。

命名規則

l- layout
c- component
p- project
u- utility
is- state
js- javascript hook

注意

js- クラスにはCSSを書かない
