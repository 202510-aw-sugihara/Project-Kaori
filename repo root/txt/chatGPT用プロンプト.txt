あなたは経験豊富なフロントエンドエンジニアです。
以下の条件に従って、静的Webサイトのフロントエンド一式（HTML / SCSS / CSS / JavaScript） を実装してください。

このサイトは GitHub Pagesで公開する静的サイトです。
そのため、バックエンド処理・API通信・サーバー依存・ビルド前提の実行環境は使わないでください。
JavaScriptは Vanilla JSのみ 使用してください。

目的は、「オリジナル香水作り体験」サイトを、スマホでも使いやすく、予約導線が分かりやすい形で実装することです。

CSS衝突防止

このプロジェクトには、既存ドキュメントHTML/CSSが同じ保存先に存在します。
そのため、CSS衝突を防ぐために以下を必ず守ってください。

すべてのページで body を以下にする
<body class="perfume-site">

すべてのスタイルは .perfume-site 配下で定義する

例

.perfume-site .l-header {}
.perfume-site .c-button {}
.perfume-site .p-home-hero {}

style.css は使わない

使用するCSSファイル名は site/assets/css/perfume.css とする

HTMLでは以下を読み込むこと

<link rel="stylesheet" href="assets/css/perfume.css">

※ 各HTMLは site/ フォルダ直下に置くため、HTMLから見た相対パスは assets/css/perfume.css とすること。

トップページの口コミセクション仕様

トップページの口コミ部分は、自社で直接投稿を管理するレビュー一覧ではなく、外部口コミ（例：じゃらん、Google など）を紹介する表示領域として実装してください。

ただし、このサイトは静的サイトであり、外部API連携は行わないため、以下の方針で実装してください。

外部口コミを掲載する想定のUIとして作る

c- = component

p- = project / page specific

u- = utility

is- = state

js- = JavaScript hook only
