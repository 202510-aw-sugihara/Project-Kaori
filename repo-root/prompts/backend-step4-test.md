# Backend Implementation Step 4: Test

このステップでは、JUnit / Spring Boot Test / MockMvc を使用してテストを実装し、ビルド品質を担保します。

## ✅ 目標
- 主要な機能について自動テストを追加する
- Mapper の SQL クエリが意図どおり動作することを検証
- API が期待どおりのステータスとレスポンスを返すことを確認

## 🧱 やること
### 1. Web レイヤー（MockMvc）
- admin 認証成功/失敗
- 未認証アクセス → 401
- role=customer で admin API へアクセスすると 403
- 予約一覧取得
- 予約詳細取得
- 予約作成成功
- 予約作成バリデーションエラー
- 予約作成オーバーキャパシティ → 409
- 予約キャンセル成功
- 予約二度目キャンセル → 409
- 公開予約作成成功
- 公開予約で管理者メールアドレス利用禁止 → 403

### 2. Mapper テスト（H2）
- 予約リストの JOIN クエリが正しくデータを返す
- 予約詳細取得クエリに参加者が含まれる
- フィルタ条件（ステータス・顧客名部分一致・日付）が効く

### 3. サービステスト
- 予約作成時の容量チェック・予約枠チェック・参加者チェック
- 予約変更で `reserved_count` が調整される
- 予約キャンセルで `reserved_count` がデクリメントされる

---

> **備考**
> - テストは `src/test/java` に配置
> - `@SpringBootTest` + `@AutoConfigureMockMvc` で Web レイヤーをテスト
> - `application-test.yml` を読み込ませて H2 に切り替える
