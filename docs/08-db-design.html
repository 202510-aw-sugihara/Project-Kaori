2 テーブル定義

テーブル名：users 必須
テーブルの目的：会員および管理者アカウント情報を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
name VARCHAR(100) NO - NOT NULL 氏名
email VARCHAR(255) NO - NOT NULL, UNIQUE メールアドレス（ログインID）
password_hash VARCHAR(255) NO - NOT NULL ハッシュ化済みパスワード
phone VARCHAR(20) YES NULL - 電話番号
role VARCHAR(20) NO 'customer' NOT NULL 権限区分（customer / admin）
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：plans 必須
テーブルの目的：体験プラン情報を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
name VARCHAR(100) NO - NOT NULL プラン名
description TEXT YES NULL - プラン説明
duration_minutes INT NO - NOT NULL 所要時間（分）
price DECIMAL(10,2) NO 0.00 NOT NULL 料金
capacity INT NO 1 NOT NULL 定員
is_active BOOLEAN NO TRUE NOT NULL 有効フラグ
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：plan_time_slots 必須
テーブルの目的：各プランの予約可能日時枠を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
plan_id BIGINT NO - FK, NOT NULL プランID（plans.id）
slot_date DATE NO - NOT NULL 開催日
start_time TIME NO - NOT NULL 開始時刻
end_time TIME NO - NOT NULL 終了時刻
capacity INT NO 1 NOT NULL この枠の定員
reserved_count INT NO 0 NOT NULL 予約済人数
is_open BOOLEAN NO TRUE NOT NULL 予約受付可否
（plan_id, slot_date, start_time） - NO - UNIQUE 同一プランの同一日時枠の重複登録を防止する複合ユニーク制約
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：reservations 必須
テーブルの目的：予約情報を管理する

※ reservation_date および start_time は、plan_time_slots の参照に加え、 予約時点の表示情報を保持するスナップショット項目として管理する。

カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
user_id BIGINT NO - FK, NOT NULL 予約者ID（users.id）
plan_id BIGINT NO - FK, NOT NULL プランID（plans.id）
plan_time_slot_id BIGINT NO - FK, NOT NULL 予約枠ID（plan_time_slots.id）
reservation_date DATE NO - NOT NULL 予約日（予約時点スナップショット）
start_time TIME NO - NOT NULL 開始時刻（予約時点スナップショット）
status VARCHAR(20) NO 'pending' NOT NULL 予約状態（pending / confirmed / cancelled / completed）
participant_count INT NO 1 NOT NULL 参加人数
total_price DECIMAL(10,2) NO 0.00 NOT NULL 合計金額
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：reservation_participants 必須
テーブルの目的：予約ごとの参加者情報を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
reservation_id BIGINT NO - FK, NOT NULL 予約ID（reservations.id）
participant_name VARCHAR(100) NO - NOT NULL 参加者氏名
participant_name_kana VARCHAR(100) YES NULL - 参加者氏名カナ
age_group VARCHAR(30) YES NULL - 年齢層
allergy_note TEXT YES NULL - アレルギー等の注意事項
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：note_types 必須
テーブルの目的：香りのノート分類を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
name VARCHAR(50) NO - NOT NULL, UNIQUE ノート分類名
display_order INT NO 0 NOT NULL 表示順
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
テーブル名：fragrances 必須
テーブルの目的：香料マスタを管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
name VARCHAR(100) NO - NOT NULL 香料名
name_en VARCHAR(100) YES NULL - 英語名
brand VARCHAR(100) YES NULL - ブランド名
note_type_id BIGINT NO - FK, NOT NULL ノート分類ID（note_types.id）
description TEXT YES NULL - 香料説明
is_active BOOLEAN NO TRUE NOT NULL 有効フラグ
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：perfume_recipes 必須
テーブルの目的：ユーザーが作成した香水レシピのヘッダ情報を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
user_id BIGINT NO - FK, NOT NULL 作成ユーザーID（users.id）
reservation_id BIGINT YES NULL FK 紐づく予約ID（reservations.id）
recipe_name VARCHAR(100) NO - NOT NULL レシピ名
concept VARCHAR(255) YES NULL - コンセプト
memo TEXT YES NULL - メモ
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：recipe_items 必須
テーブルの目的：香水レシピに含まれる香料明細を管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
recipe_id BIGINT NO - FK, NOT NULL レシピID（perfume_recipes.id）
fragrance_id BIGINT NO - FK, NOT NULL 香料ID（fragrances.id）
drops INT YES NULL - 滴数
ratio_percent DECIMAL(5,2) YES NULL - 配合比率（%）
sort_order INT NO 0 NOT NULL 表示順
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
テーブル名：reviews 必須
テーブルの目的：体験後レビューを管理する
カラム名 データ型 NULL デフォルト 制約 説明
id BIGINT NO AUTO_INCREMENT PK 主キー
reservation_id BIGINT NO - FK, NOT NULL, UNIQUE 予約ID（reservations.id）。1予約につきレビュー1件のみ投稿可能
user_id BIGINT NO - FK, NOT NULL 投稿ユーザーID（users.id）
rating INT NO - NOT NULL 評価（1〜5想定）
title VARCHAR(100) YES NULL - レビュータイトル
comment TEXT YES NULL - レビュー本文
created_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 作成日時
updated_at DATETIME NO CURRENT_TIMESTAMP NOT NULL 更新日時
deleted_at DATETIME YES NULL - 論理削除日時
外部キー制約一覧 必須
テーブル間の参照整合性を担保するための制約一覧
plan_time_slots.plan_id                 → plans.id
reservations.user_id                    → users.id
reservations.plan_id                    → plans.id
reservations.plan_time_slot_id          → plan_time_slots.id
reservation_participants.reservation_id → reservations.id
fragrances.note_type_id                 → note_types.id
perfume_recipes.user_id                 → users.id
perfume_recipes.reservation_id          → reservations.id
recipe_items.recipe_id                  → perfume_recipes.id
recipe_items.fragrance_id               → fragrances.id
reviews.reservation_id                  → reservations.id
reviews.user_id                         → users.id

3 インデックス設計

インデックス一覧 必須
テーブル名 インデックス名 対象カラム 種類 設定理由
users uk_users_email email UNIQUE ログイン時の検索およびメールアドレス重複防止のため
users idx_users_role role INDEX 管理者・一般ユーザーの権限別検索で利用されるため
users idx_users_deleted_at deleted_at INDEX 論理削除除外条件（deleted_at IS NULL）で利用するため
plans idx_plans_is_active is_active INDEX 公開中プランのみを一覧取得する条件で利用されるため
plans idx_plans_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
plan_time_slots idx_plan_time_slots_plan_id plan_id INDEX 外部キー結合およびプランごとの時間枠取得で利用するため
plan_time_slots idx_plan_time_slots_slot_date slot_date INDEX 日付指定で予約枠を検索するため
plan_time_slots idx_plan_time_slots_plan_date_time plan_id, slot_date, start_time UNIQUE 同一プランの同一日時枠の重複防止と、プラン別・日付別の予約枠検索および開始時刻順表示で利用するため
plan_time_slots idx_plan_time_slots_is_open is_open INDEX 受付中の時間枠のみを取得する条件で利用するため
plan_time_slots idx_plan_time_slots_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
reservations idx_reservations_user_id user_id INDEX ユーザーごとの予約履歴取得で利用するため
reservations idx_reservations_plan_id plan_id INDEX プラン別の予約集計や一覧表示で利用するため
reservations idx_reservations_plan_time_slot_id plan_time_slot_id INDEX 予約枠単位での検索および外部キー結合で利用するため
reservations idx_reservations_date reservation_date INDEX 日付単位の予約検索で利用するため
reservations idx_reservations_status status INDEX 予約状態別の絞り込みに利用するため
reservations idx_reservations_user_created_at user_id, created_at INDEX マイページで予約履歴を新しい順に表示する用途を想定しているため
reservations idx_reservations_date_start_time reservation_date, start_time INDEX 管理画面で日付順・時刻順に予約一覧を表示するため
reservations idx_reservations_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
reservation_participants idx_reservation_participants_reservation_id reservation_id INDEX 外部キー結合および予約に紐づく参加者一覧取得で利用するため
reservation_participants idx_reservation_participants_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
note_types uk_note_types_name name UNIQUE ノート分類名の重複防止のため
note_types idx_note_types_display_order display_order INDEX 表示順でソートして一覧表示するため
fragrances idx_fragrances_note_type_id note_type_id INDEX 外部キー結合およびノート分類別の検索で利用するため
fragrances idx_fragrances_is_active is_active INDEX 有効な香料のみを取得する条件で利用するため
fragrances idx_fragrances_name name INDEX 香料名検索や管理画面の絞り込みで利用するため
fragrances idx_fragrances_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
perfume_recipes idx_perfume_recipes_user_id user_id INDEX ユーザーごとのレシピ一覧取得で利用するため
perfume_recipes idx_perfume_recipes_reservation_id reservation_id INDEX 予約に紐づくレシピ検索で利用するため
perfume_recipes idx_perfume_recipes_user_created_at user_id, created_at INDEX ユーザー別に作成日順でレシピ一覧を表示するため
perfume_recipes idx_perfume_recipes_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
recipe_items idx_recipe_items_recipe_id recipe_id INDEX 外部キー結合およびレシピごとの明細取得で利用するため
recipe_items idx_recipe_items_fragrance_id fragrance_id INDEX 香料別の利用状況集計や外部キー結合で利用するため
recipe_items idx_recipe_items_recipe_sort_order recipe_id, sort_order INDEX レシピ詳細表示時に表示順で明細を取得するため
recipe_items uk_recipe_items_recipe_fragrance recipe_id, fragrance_id UNIQUE 同一レシピ内で同一香料の重複登録を防止するため
recipe_items idx_recipe_items_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
reviews uk_reviews_reservation_id reservation_id UNIQUE 1予約につき1レビューに制限するため
reviews idx_reviews_user_id user_id INDEX ユーザーごとのレビュー一覧取得で利用するため
reviews idx_reviews_rating rating INDEX 評価別の集計や絞り込みで利用するため
reviews idx_reviews_created_at created_at INDEX 新着順表示で利用するため
reviews idx_reviews_deleted_at deleted_at INDEX 論理削除除外条件で利用するため
