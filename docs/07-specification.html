1 システム概要

システムの目的 必須
このシステムが解決する課題と提供する価値

本システムは、店舗スタッフおよび管理者が利用する予約管理システムである。 予約情報の確認、キャンセル対応、顧客情報の管理などを一元的に行うことで、 手作業による管理の負担を軽減し、運営管理の効率化と顧客対応品質の向上を 実現することを目的とする。

本システムは、Webブラウザをクライアントとした三層構造のWebアプリケーションとして構成されている。 ブラウザから送信されたHTTPリクエストはSpring Bootアプリケーションで処理され、 Controller・Service・Repositoryの各レイヤーを通じてデータベースへアクセスする。 取得したデータはThymeleafによってHTMLとして生成され、ブラウザへレスポンスとして返却される。

4 機能詳細仕様

主要機能詳細仕様

機能名：管理者ログイン 必須
機能ID：F-001

1. 画面レイアウト
メールアドレス入力欄、パスワード入力欄、ログインボタンを縦配置するシンプルなログインフォームを表示する。 入力エラー時には各入力欄の下にエラーメッセージを表示する。

2. 処理フロー
管理者がメールアドレスとパスワードを入力してログインボタンを押下する。 システムは入力値を検証後、Spring Securityによる認証処理を実行する。

3. 正常時の動作
認証成功時は管理者セッションを発行し、予約一覧画面へ遷移する。

4. エラー時の動作
認証失敗時は「メールアドレスまたはパスワードが正しくありません」と表示する。

5. 画面遷移先
成功：予約一覧画面
失敗：ログイン画面

パスワード String ○ 未入力不可 / 8文字以上 マスク表示
機能名：予約一覧表示 必須
機能ID：F-003

1. 画面レイアウト
予約情報をテーブル形式で表示する。カラムは「予約日」「時間」「顧客名」「人数」「ステータス」「操作」とする。 上部には検索条件エリアを配置し、必要に応じてソート・ページ切替・CSV出力の操作を行えるようにする。

2. 処理フロー
画面表示時に予約データを取得し一覧表示する。検索条件入力時は再検索を実行し、 詳細ボタン押下時は対象予約の詳細画面へ遷移する。

3. 正常時の動作
該当する予約データをページ単位で表示する。検索条件やソート条件に応じて結果を更新する。

4. エラー時の動作
データ取得失敗時はエラーメッセージを表示する。検索条件に一致する予約が存在しない場合は 「該当する予約はありません」と表示する。

機能名：予約編集 必須
機能ID：F-006

1. 画面レイアウト
画面上部にページタイトル「予約編集」を配置し、その下に編集フォームを縦並びで表示する。 フォーム内には「予約日」「予約時間」「コース」「人数」「顧客名」「メールアドレス」「電話番号」 「備考」を配置し、画面下部に「保存」ボタンと「キャンセル」ボタンを配置する。

5 非機能要件

セキュリティ要件 必須
認証・認可・データ保護に関する要件

本システムでは、管理画面への不正アクセス防止と顧客情報の保護を目的として、 以下のセキュリティ要件を満たすものとする。

1. 認証方式
認証はSpring Securityを用いて実装する。管理者はログイン画面からメールアドレスおよび パスワードを入力して認証を行い、未認証ユーザーは管理画面へアクセスできない。 認証が必要なURLにはアクセス制御を設定し、ログイン後のみ利用可能とする。

2. パスワードの暗号化方式
パスワードは平文で保存せず、BCryptによるハッシュ化を行ったうえで保存する。 認証時は入力値と保存済みハッシュ値を照合し、パスワードの復号は行わない。

3. CSRF対策
Spring SecurityのCSRF保護機能を有効化する。登録・更新・削除・キャンセルなど 状態を変更するリクエストにはCSRFトークンを付与し、正しいトークンを持たない リクエストは拒否する。

4. XSS対策
入力値を画面表示する際は、Thymeleafの標準エスケープ機能を利用して HTMLとして危険な文字列をそのまま出力しない。備考欄などの自由入力項目には、 必要に応じてサニタイズまたは文字数制限を設ける。

5. SQLインジェクション対策
データベースアクセスはRepository、ORM、またはプレースホルダ付きSQLを利用し、 文字列連結によるSQL生成を避ける。ユーザー入力値をそのままSQL文へ埋め込まず、 バインド変数を用いて安全に処理する。

6. セッション管理
ログイン成功時にセッションを発行し、認証状態を管理する。ログアウト時には セッションを無効化し、ログイン成功時にはセッションIDを再生成する。 また、一定時間操作がない場合はセッションをタイムアウトさせ、再認証を求める。

対応ブラウザ・デバイス

本システムはWebブラウザを利用してアクセスするWebアプリケーションとして提供される。 サーバー側はSpring Bootアプリケーションとして動作し、ブラウザを通じて予約管理および顧客情報管理を行う。

対応ブラウザ
Google Chrome（最新版）
Mozilla Firefox（最新版）
Microsoft Edge（最新版）
※Internet Explorerには対応しない

対応デバイス
PC（Windows / macOS）
タブレット（iPad / Android タブレット）
スマートフォン（iOS / Android）

サーバー環境
アプリケーションフレームワーク：Spring Boot
テンプレートエンジン：Thymeleaf
データベース：MySQL（本番環境） / H2（開発環境）
Java実行環境：Java 17 以上

ネットワーク環境
本システムはインターネットまたは社内ネットワークを通じてアクセスするWebシステムとして提供される。 ブラウザとサーバー間の通信はHTTPまたはHTTPSを使用する。
