1 プロジェクト概要

サービス名 必須
制作するWebサービスの名前

オリジナル香水作り体験

コンセプト 必須
サービスを一言で表す説明（キャッチコピー＋1〜2文の説明）

■キャッチコピー
香りを、つくる時間。

■コンセプト
12種および月末限定20種の香料から自分の感性で選び、ブレンドして完成させる体験型ワークショップ。
完成品を持ち帰るだけでなく、「選ぶ」「迷う」「組み立てる」プロセスそのものを価値とする。
初心者でも安心して参加できる設計により、観光・記念日・自己投資の体験として選ばれるサービスを目指す。

ターゲットユーザー 必須
このサービスを使う主なユーザー像（概要レベル）
  1. 20代〜40代の女性
    • 休日に体験型アクティビティを探している
    • SNSで写真や体験レポートを参考にする
    • 自己投資やご褒美体験に価値を感じる
  2. カップル（20代〜30代）
    • デートで“特別感のある体験”を求めている
    • 記念日や旅行の思い出づくりを重視
    • 一緒に何かを作る体験に価値を感じる
  3. 観光客（国内・国外）
    • 地域ならではの体験を求めている
    • 「作った」という体験価値を重視
    • 思い出に残るお土産を求めている

2 背景と課題

市場の現状 必須
このサービスが存在する市場の現状と課題

体験型ワークショップ市場は拡大しており、特に20代〜40代女性やカップル層は「モノ」よりも「体験」に価値を感じる傾向が強い。
観光客にとっても、その土地ならではの体験は重要な選択基準となっている。
一方で、類似する体験サービスも増加しており、価格や写真の印象で比較されやすい状況にある。
香水作り体験は特に「自分にできるか分からない」「失敗したくない」といった心理的ハードルが高く、Web上で十分な情報が提示されない場合、予約離脱につながりやすい。

解決すべき課題 必須
本プロジェクトで解決を目指す具体的な課題（3つ程度）
  1. 12種ブレンド体験と20種（月末限定）体験の違いが直感的に理解できない
    2. → ユーザーが「どちらを選ぶべきか」判断できない状態が発生している。
  2. 初心者でも安心して参加できることが十分に伝わっていない
    3. → “難しそう”という印象が離脱につながっている可能性がある。
  3. スマートフォン中心の閲覧環境に対して、予約導線が最適化されていない
    4. → 予約直前で離脱している可能性がある。
  4. 月末限定20種体験の「今予約する理由」が弱い
    5. → 限定性が十分に行動動機として機能していない。

3 提案するソリューション

サービスの特長 必須
競合と差別化するサービスの特長を3つ
  1. 比較できるブレンド体験設計
    12種と月末限定20種の違いを明確にし、ユーザーが自分に合った体験を選べる構造を持つ。
  2. 初心者でも参加しやすい安心設計
    香水の知識がなくても楽しめるサポート体制により、心理的ハードルを下げている。
  3. 限定開催による特別価値
    20種体験を月末限定とすることで、特別感と予約動機を生み出している。

4 制作範囲

Webサイト（フロントエンド）の範囲 必須
制作するWebサイトのページ一覧と概要
  1. トップページ（/）
    • オリジナル香水作り体験の訴求強化
    • 12種／20種の比較セクション新設
    • ファーストビューに予約CTA設置
    • 固定予約ボタン実装
    • スマートフォン最適化調整

  2. 12種ブレンド体験ページ（/ ?mode=f17）
    • 体験内容の再構成（流れの明確化）
    • 初心者歓迎の明示
    • おすすめ対象の表示
    • 予約導線の最短化

  3. 20種（月末限定）体験ページ（/ ?mode=f18）
    • 限定性の強調
    • 通常コースとの違いの明確化
    • 残席／開催日の強調表示
    • 予約動機を高める構成に再設計

  4. 共通改善
    • 比較表セクションの実装
    • FAQ強化
    • 写真／体験イメージの最適化
    • 導線の一貫性整理
Webアプリケーション（サーバーサイド）の範囲 必須
制作するWebアプリケーションの機能概要
  • 予約フォーム機能
  • 日程選択機能
  • 残席管理機能
  • 予約データ保存機能
  • 管理画面（予約一覧確認）
  • 予約ステータス管理（確定／キャンセル）
  • 自動返信メール機能
