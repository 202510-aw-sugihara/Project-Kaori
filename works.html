Project Kaori - オリジナル香水作成ワークショック予約システム

作品概要 必須
どんなサービス・サイトか、ターゲットユーザーは誰か

香水ワークショップ「ShizuKa」の予約システム。ユーザーがオンラインでコースを選択し、日時を予約できるウェブアプリケーション。バックエンドにSpring Bootを使用し、データベース連携で予約管理を実現。

使用技術 必須

フロントエンド：HTML / CSS / JavaScript

バックエンド：Java / Spring Boot / MyBatis

データベース：MySQL

その他：Git / figma / Thymeleaf

担当範囲 必須
企画・デザイン・フロントエンド・バックエンドなど

企画・要件定義、データベース設計、バックエンド開発（Spring Boot, MyBatis）、フロントエンド開発（HTML/CSS/JS）、テスト・デプロイ

工夫した点・アピールポイント 必須

予約システムのロジック実装で、コースと日時の組み合わせを効率的に管理。ユーザーエクスペリエンスを重視した直感的なUI設計。データベースの正規化でデータの整合性を確保。セキュリティ対策として入力バリデーションを実装。
